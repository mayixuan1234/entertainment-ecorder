# 娱乐记录器 Entertainment Recorder（Orbit Log）

> 娱乐内容记录网站 | 状态：已部署 / 暂停开发

在线地址：https://entertainment-ecorder.pages.dev/

## 项目是什么 / 为什么做
用于记录看过的书 / 影视 / 剧等娱乐内容的个人记录工具，支持基本分类、角色设定记录、查看与导出。

## 解决什么问题
娱乐内容（尤其是多角色设定的作品）记忆零散，需要一个轻量的记录与回看入口。

## 技术栈
- HTML + Tailwind CSS（CDN）
- Font Awesome 图标
- html2canvas（截图导出）
- localStorage 本地存储

## 当前状态
基本功能可用，但角色设定记录表显示与导出效果存在问题，且未持续更新。**半成品 / 暂停**，除非以后自己有真实使用需求，否则不再投入。
